  • 사내 플랫폼의 챗 서비스에서 사용자가 자신의 배경을 반복해서 설명해야 하는 문제를 발견하고, 대화 이력과 별도로 반복 활용할 정보를 보존하는 프로필 메모리 도입을 제안했습니다.
  • 기존 메모리 구조에서는 반복적인 LLM 호출로 갱신이 지연되고, 응답에 활용되지 않는 정보도 누적됐습니다. 사내 업무 응답에 필요한 직무와 관심사, 기술 정보를 선별해 저장하도록 적재 기준을 정했습니다. 갱신 시에는 프로필을 매번 새로 생성하는 대신 기존 유사 메모리를 조회하고, 추가·수정·삭제·유지 여부를 판단해 재사용하도록 구성했습니다.
  • 저장한 정보가 실제 개인화에 기여하는지 확인하기 위해, 사용자 맥락에 따라 정답이 달라지는 약어 해석을 평가 과제로 선정했습니다. 실제 대화 기반 평가에서 약어 해석 정확도는 68.94%에서 80.40%로 높아졌습니다. 또한 유사 메모리 조회 방식을 적용한 결과, 기존 구조보다 LLM 호출 횟수가 줄었으며 중복 저장과 잘못된 갱신을 줄여 적재 안정성을 높였습니다.
  • 대량 갱신을 사용자별 작업과 대화 구간별 비동기 처리로 분리하고, 서빙 API의 처리 제약에 맞춰 동시 호출 수를 제한했습니다. 완료된 작업은 유지하고 실패 구간만 재처리하도록 구현해 전체 재실행 부담을 줄였으며, 사내 플랫폼에 적용해 운영했습니다.

업무 맥락과 실행 경험을 보존하는 장기메모리

2026.08 – 현재

구조 제안, 메모리 설계 및 비교 평가 주도

여러 대화에 흩어진 업무 정보와 변경 이력, 실행 경험을 다음 작업에 활용하는 사내 플랫폼용 장기메모리 프레임워크를 설계하고 구현했습니다. 사실과 출처를 보존하는 Fact, 업무 맥락을 통합하는 Wiki, 수행 과정과 교훈을 기록하는 경험 기억으로 구성하고, 기존 메모리 프레임워크와의 비교 평가로 성능을 검증했습니다.

  • 과거 대화 검색만으로는 업무의 변경 이력과 현재 유효한 기준을 다시 조합해야 했고, Wiki 중심의 요약에서는 수치와 적용 시점, 조건이 생략됐습니다. 사실의 보존과 맥락의 통합을 분리해야 한다고 판단해, 대상과 값, 시점, 화자, 출처를 보존한 Fact를 업무 Wiki에 연결하는 그래프 구조를 설계했습니다. 새 정보가 들어오면 기존 근거를 유지하면서 변경 내용과 적용 시점을 통합하도록 구성했습니다.
  • 개별 사실만 검색하면 업무의 전체 흐름을 파악하기 어렵고, 통합된 Wiki만 검색하면 답변에 필요한 정확한 값과 조건을 놓칠 수 있다고 판단했습니다. Wiki에서 업무 관계와 현재 상태를 찾고, 연결된 Fact에서 세부 근거를 확인하도록 검색 구조를 구성했습니다.
  • 검색된 정보를 모두 답변 모델에 전달하면 현재 대화에 사용할 입력 공간이 줄고, 다른 사건의 수치나 조건이 섞일 수 있었습니다. 질문에 필요한 관계와 시간 조건을 기준으로 근거를 선별하는 Curating 단계를 도입했습니다. 선택한 근거는 다시 요약하지 않고 저장된 문장과 출처로 전달해, 입력량을 조절하면서도 판단에 필요한 값과 조건을 보존하도록 구성했습니다.
  • 대화에 흩어진 사실과 시간 맥락을 기억하는 능력은 LoCoMo로, 여러 문서의 근거를 연결하는 다중 홉 추론 능력은 MuSiQue로 평가했습니다. Mem0, HippoRAG 2 등 다양한 적재 방식의 장기메모리 프레임워크와 비교한 결과, 두 평가에서 가장 높은 F1을 기록했으며 비교군 최고 점수보다 각각 2.42%p와 10.07%p 높았습니다. 이를 통해 정확한 사실과 통합된 업무 맥락을 함께 제공하려는 설계 방향이 대화 기억과 근거 연결 성능에 효과적임을 평가 점수로 확인했습니다.

Pokémon Red의 입력 전처리, 진행 상태 관리, 행동 결정 설계 및 구현

모델의 추론 능력을 고려해 Pokémon Red의 진행 목표를 200 step 안에 달성하는 게임 Agent를 개발했습니다. 제한된 행동 횟수 안에 탐색과 이동, 대화, 전투를 수행하도록 구성했습니다.

  • 프론티어 모델이 처리하던 복합 판단을 소형 모델에 요구하자 좌표 오류와 반복 행동이 발생했습니다. 원시 게임 상태에서 현재 목표와 이동 경로, 실행할 행동을 동시에 판단해야 하는 부담이 주요 원인이라고 분석했습니다.
  • 모델이 한 번에 수행할 판단의 범위를 줄이기 위해 목표 설정과 이동, 대화, 전투를 분리했습니다. 현재 하위 목표와 완료 조건을 제공하고, 상태별로 필요한 정보와 도구를 구성해 한 번에 하나의 과제에 집중하도록 Agent 워크플로우를 설계했습니다.
  • 과제를 분리한 뒤에도 소형 모델은 이동 가능 여부와 경로 판단에서 오류를 보여, 주어진 step 안에 목표를 달성하지 못했습니다. 그래프 탐색으로 이동 후보를 미리 계산하고, 모델이 현재 목표에 적합한 후보를 선택하도록 과제를 전환했습니다. 변경 후에는 소형 모델도 유효한 이동을 선택하며 진행했고, 200 step 안에 목표를 달성했습니다.
  • 도구 호출이 정상적으로 끝나도 실제 이동이나 목표 진행이 이뤄지지 않는 사례를 확인했습니다. 실행 전후의 좌표와 화면, 전투 및 소지품 변화를 비교해 무효 행동과 반복 실패를 점검하고, 직전 행동과 상태 변화를 다음 판단에 반영하도록 개선했습니다.

고객사 추천 시나리오 조율, 평가 지표 설계, DB Tool 및 Agent 워크플로우 구현

고객사의 회원, 구매 이력과 상품 DB를 연결해 자연어 요청에 맞는 상품을 추천하는 Agent PoC입니다. 필수 조건이 불명확할 때 모델이 값을 추측하는 대신 사용자에게 확인한 뒤 추천을 이어가도록 실행 흐름을 설계했습니다.

  • 과거 구매 이력만으로는 현재 요청과 선물 대상의 조건을 반영하기 어렵다고 판단해, 회원 정보와 현재 요청을 구분해 활용하도록 구성했습니다. 본인용 추천에는 회원 정보를 미리 제공하고, 요청에 따라 상품과 브랜드, 행사를 조회했습니다. 성별과 연령, 고객군별 인기 상품에 카테고리와 가격 조건을 적용하고, 조회한 상품 속성과 회원 정보를 추천 이유에 연결했습니다.

  • 도구 호출이 성공해도 모델이 누락된 가격 조건이나 선물 대상의 정보를 임의로 채워 부적절한 상품을 추천하는 문제가 발생했습니다. 처음에는 프롬프트 보강으로 해결을 시도했지만 이로 해소되지 않아, DB에서 확인할 정보와 사용자에게 물어야 할 정보를 구분했습니다. 본인과 선물 대상의 정보를 분리하고, 대상 정보가 부족하면 현재 실행을 종료한 뒤 확인 질문을 반환하도록 워크플로우를 변경했습니다.

검색 Agent가 검증되지 않은 중간 후보를 다음 탐색의 전제로 사용하는 실패 패턴을 발견하고 분석했습니다. 최종 정답률에 가려진 탐색 과정의 문제를 진단하는 평가 체계를 설계하고, 여러 Agent 설정의 비교 분석을 통해 개선 방향을 제안했습니다.

  • 병렬 검색의 중복을 메모리로 조정하는 접근에서 출발했으나, 순차 검색에서도 조건 검증이 끝나지 않은 후보에 의존해 후속 탐색을 진행하는 실패를 발견했습니다. 병렬 실행의 조율에 앞서 후보를 발견한 뒤 충분한 검증 없이 다음 탐색으로 넘어가는 과정을 분석해야 한다고 판단해 연구 문제를 재정의했습니다.
  • 후보의 발견을 조건 충족으로 간주하고 에이전트가 검증되지 않은 가정에 의존해 탐색하는 문제를 진단하기 위해 질문을 대상과 연결 개체, 세부 요구조건으로 분해하고, 단서 발견과 조건 충족을 구분하는 평가 기준을 설계했습니다. 최종 답변의 정답 여부와 함께 탐색 과정에서 필요한 근거를 확보했는지 평가하도록 구성했습니다.
  • 순차 검색과 병렬 검색, 강화학습 기반 Agent 등 다양한 설정에서 비교 평가했습니다. 기존 방법의 검색 결과 선택과 요약 규칙을 유지한 상태에서 평균 정답률 17.5%와 근거 완결성까지 충족한 인증 정확도 2.5%의 격차를 확인했습니다. 정답을 도출한 경우에도 필요한 조건의 검증이 누락될 수 있음을 확인하고, 최종 정답률만으로는 파악하기 어려운 탐색 과정의 실패를 분석했습니다. 또한 LLM의 모델 사이즈, 에이전트 구성요소와 관계없이 후보를 검증하기보다 다음 후보를 찾아가는 행동을 수행함을 확인할 수 있었습니다.
  • 분석 결과를 바탕으로 미해결 조건을 추적하고, 후속 탐색의 전제로 사용할 후보를 먼저 검증하는 행동을 후속 학습 목표로 제안했습니다. 발견한 실패 패턴을 구체적인 탐색 행동의 개선 방향으로 연결하고, 실패 분석과 평가 체계를 연구 기여로 정리해 AAAI 2027에 제1저자로 제출했습니다.

ECO Decoding, 엔트로피 기반 대화 생성 제어

2023 – 2025

EMNLP 2025 Main Conference 제1저자, 문제 정의, 알고리즘 설계, 실험 및 논문 작성

대화 응답의 감정과 대화행위를 제어하면서 문법 품질을 유지하는 ECO Decoding을 연구했습니다.

  • 기존 weighted decoding은 제어 강도를 높일수록 문법과 유창성이 저하됐습니다. 고정 가중치가 생성 단계별 불확실성을 반영하지 못한다고 판단해, 기반 언어모델을 추가 학습하는 대신 토큰마다 제어 강도를 조절하는 방법을 선택했습니다.
  • 언어모델이 확신하는 출력은 보존하고, 불확실한 단계에서는 속성 제어를 강화하면 제어 정확도와 문법 품질을 함께 확보할 수 있다는 가설을 세웠습니다. 이를 바탕으로 언어모델과 속성 분류기의 엔트로피를 함께 활용해 토큰별 가중치를 결정하는 ECO Decoding을 설계했습니다.
  • 제어 정확도 향상이 문법 품질 저하를 동반하는지 확인하기 위해, 유사한 문법 점수에서 기존 방법과 비교했습니다. DailyDialog 감정 제어의 DialoGPT 기반 FUDGE 설정에서 정확도를 76.98%에서 81.03%로 4.05%p 높였으며, 문법 점수는 90.30에서 90.34로 유지했습니다.
  • 성능 향상이 제안한 가설에 따른 결과인지 확인하기 위해 품사별 엔트로피 분석, 구성 요소 제거, 가중치 방향을 반대로 적용한 실험을 수행했습니다. 자동 평가와 사람 평가를 통해 생성 품질을 점검하고, 토큰별 불확실성에 따른 제어 강도 조절이 성능 향상에 기여함을 확인했습니다. 이를 통해 기반 언어모델의 추가 학습 없이도, 모델이 확신하는 출력은 보존하고 불확실한 단계에서 제어를 강화하는 방식으로 제어 정확도와 문법 품질 간의 상충을 완화할 수 있음을 보였습니다.
